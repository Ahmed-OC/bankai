# Domain-Fit (desengs) — the interface must fit the need, not the habit

Source: research synthesis across industry-specific design literature. Core psychology: every domain sits on a map of **stakes** (money/health/safety = high cost of error) vs **aspiration** (delight IS the product in creative/play domains). High-stakes domains buy confidence through restraint; low-stakes domains buy attention through variance. This skill converts that map into concrete settings.

## The decision procedure (run after the master's §1)

1. **Base settings from the domain matrix** (below) → palette temperature, type voice, default density, imagery material, trust furniture.
2. **Mode modifier**: Operate → density +2 steps, motion −50%, ornament → 0, tabular numerals. Create → neutral canvas, compact chrome, delight only on save/publish. Consume → density −1, reading-optimized type, motion only for continuity. Entice → variance +2, display ambition allowed, trust furniture maximized. Play → variance max, physics character, ornament is content.
3. **Audience-risk multiplier**: risk = stakes × user vulnerability (someone's savings/diagnosis/child > someone's evening). Risk ↑ ⇒ chroma discipline ↑ (accents reserved for semantics), motion variance ↓, empty-state humor ↓, compliance furniture ↑, contrast ↑. Risk ↓ ⇒ allow warmth, wit, variance that buys memorability.
4. **Conflict rule**: when mode wants more variance than domain allows (fintech Entice, health landing), spend the variance budget on **one dimension only** — typography scale, OR motion craft, OR one bold accent — never all; restraint elsewhere is what makes the single flourish read as confidence.
5. **Cliché check**: before shipping, diff against the domain's slop list; ≥2 matches ⇒ re-derive from psychology (what emotion does this user need: trust/care/precision/delight?) instead of the domain's visual clichés.

## The domain matrix

**Fintech/finance** — stability hues (navy/blue base), green strictly semantic for gains, red for loss only; low-chroma accents, near-monochrome chrome; light default retail, dark for pro terminals. Geometric sans, tabular numerals non-negotiable. Dense tables/sparklines; cards only for account summaries. Motion instrument-precise 150-250ms, no bounce; number tickers and chart reveals are the only delight. Trust: guarantees/badges, fee transparency upfront, conservative empty states. **Slop:** blue→purple gradients, glass cards, 3D coins, skyline+couple stock.

**Health/wellness** — low-arousal cool palette (soft blues/greens/sage, warm off-whites; blue/green measurably relax); saturated red only for true alerts. Rounded humanist sans, generous leading, one task per screen — anxiety reduction IS the UX. Motion slow/organic (400ms+); delight in streaks/celebrations, never in medical data. Jargon-free copy, crisis-resources footer. **Slop:** sage-everything, over-rounded blobs, lotus petals, pastel meditation loops.

**Edtech** — dual register: institutional credibility (clean sans, structured grid) for parents/schools + play for learners (saturated accents, rounded geometry, celebration systems). Warm high-energy hues — learning needs motivation scaffolding, not calm. Chunky friendly type; large targets K-12. Illustration dominates. **Slop:** owl mascots, gamification on serious subjects, purple-gradient "university of the future".

**Developer tools** — dark default canonical (IDE heritage); terminal aesthetic (mono, phosphor-green accent, command/output pairing) reads as insider authenticity. One high-chroma accent; near-black layered grays; mono-as-identity for docs/changelogs. Dense, keyboard-first, CLI-equivalence. Motion <150ms; polish = speed. Screenshots are the product shots (code blocks, terminal recordings). Trust: OSS license, install one-liner, docs quality, changelog rigor. **Slop:** fake code with syntax errors, Matrix rain, "ex-FAANG".

**B2B enterprise SaaS** — trust architecture for buyer+user dual audience. Muted blue/slate, one disciplined accent, light default (dark dashboards optional). Institutional sans, small type OK, dense filterable tables — trained users prize density. Motion functional only. Product UI screenshots + logo walls; case studies with numbers, compliance badges, role-based pricing clarity. **Slop:** Linear-clone purple-on-black for a boring product, mockups with fake data, handshake stock.

**Consumer SaaS/productivity** — "calm software" register: near-neutral canvas, one soft accent, warm grays (not pure white), generous whitespace, document metaphor. Motion subtle but craft-visible (springs) — polish signals competence to prosumers. Free-tier clarity, import/export (data exit), keyboard shortcuts. **Slop:** minimalism so severe nothing is discoverable; identical Linear-style hero.

**E-commerce** — conversion discipline over mood: category-appropriate base with high-contrast CTA in a hue absent from product photography. Product grid dense; checkout sparse, single-column (checkout UX alone worth up to +35% — Baymard). Motion minimal in the funnel (speed = trust), rich in merchandising (hover swatches, 360°). Product imagery multiple angles + zoom mandatory; trust badges NEAR the pay button; guest checkout; urgency only if real. **Slop:** countdown lies, "only 1 left" lies, carousel heroes.

**Creative studio/agency** — maximum variance budget: the portfolio IS the argument. Display type as identity (oversized, type-as-artwork), editorial or brutalist grids, risk palettes. Motion expressive and idiosyncratic (custom cursors, scroll choreography). Low density by design — one work at a time. The work full-bleed, no stock ever. Client logos paradoxically small; the craft speaks. If the studio sells identity or type, the wordmark itself must be custom (drawn SVG paths or a distinctive cut) — a stretched system font on a type studio's own page is the biggest craft tell. Route through `desengs-spectacle`. **Slop:** "We craft digital experiences" hero, rainbow gradient blobs, scroll-jack hiding the work.

**Artisan/craft** — warm material honesty: earth tones, kraft textures, cream grounds (2026 trend explicitly anti-AI-polish, pro-human imperfection). Rounded serif/hand-influenced display (rounded reads friendly vs angular sharp). Generous asymmetric spacing, editorial-product hybrid. Motion gentle: fades, texture parallax, nothing slick. Process photography (hands, workshop, ingredients), maker's face, materials list, small-batch numbers. **Slop:** fake kraft texture on dropshipped goods, script fonts as "authenticity".

**Culture/museum/editorial** — editorial serif display over archival sans (catalogue inheritance); gallery-neutral ground (bone/ink) + one curatorial accent; disciplined grids. Mixed density: airy marketing, dense calendar/collection tables. Motion restrained but conceptual (slow crossfades, reveal-on-scroll like walking a gallery). Collection imagery high-res, zoomable; citation rigor. **Slop:** neo-brutalist museum clone, posters as background, illegible art-type over artworks.

**Travel/hospitality** — emotion-first: full-bleed destination photography IS the conversion engine; UI recedes (scrim panels, one warm accent; sunset ochres/sea blues). Elegant light sans or thin serif; spacious overlays. Motion cinematic (slow Ken Burns, scroll reveals); booking flow itself fast and boring. Transparent pricing, flexible-cancellation cues, real reviews. Never illustration. **Slop:** tropical stock, "Explore/Discover/Dream" nav, search widget covering the view.

**AI products** — the dark+glow+gradient look is oversupplied; differentiate: calm neutrals + one precise accent; treat model output surfaces (chat, canvas) as calm document UIs. Technical sans + mono for prompts/tokens. Conversational low density, eval dashboards high. Motion = honest machine state (streaming, thinking). Trust: usage pricing clarity, data policy, model versioning, latency honesty. **Slop:** gradient orb, "powered by AI" badge, sparkles icon, dark-purple sameness.

**Gaming/entertainment** — highest arousal budget: near-black grounds, neon accents, glow, chromatic aberration, heavy display/italic type. Dense HUD-derived components (stat rows, rarity chips). Motion constant and kinetic but frame-rate honest. Key art and video. Trust: platform logos, ratings, system requirements. **Slop:** neon-on-black for casual games, default sci-fi font, autoplay with sound.

**Nonprofit/civic** — human warmth over polish: authentic (consented) beneficiary photography beats illustration. One hopeful accent on honest neutrals; avoid corporate navy (cold) and partisan colors. Readable humanist sans, plain language, LARGER sizes (all ages/literacies). Scannable impact stats; ONE prominent donate CTA, predictable placement. Trust: ratings, financial transparency, named impact ("$40 = one kit"). **Slop:** poverty-porn, sad-piano assumptions, donation forms longer than e-commerce checkout.

## How to apply

1. Identify domain → row → base settings; write them into the dials (master §1 Step 2).
2. Apply the mode modifier and the risk multiplier; resolve conflicts via the one-dimension rule.
3. Choose imagery material and trust furniture from the row — trust furniture is REQUIRED content on Entice surfaces (R8 pro-pass).
4. Run the cliché check against the row's slop list before the master's §7 walk.
5. If the brief spans two domains (fintech landing for developers), derive from the HIGHER-risk domain and spend variance on one dimension.

## AI-slop warning

The meta-failure this skill exists to kill: applying one house style (or the canon's own warm-ledger gravity) to every domain — a wellness app in terminal green, a bank in playful pastels, a game in calm beige. The second failure: treating the domain's clichés as the domain (blue+glass = fintech). Always derive from stakes × aspiration psychology, then check the slop list.
